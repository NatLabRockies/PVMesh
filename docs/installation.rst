Installation
============

Prerequisites
-------------

PVmesh relies on:

* Python
* Gmsh Python bindings
* PyQt5 for the GUI

Recommended environment setup
-----------------------------

From the project root:

.. code-block:: bash

   mamba env create -n pvmesh -f environment.yaml
   mamba activate pvmesh

This installs runtime, testing, and documentation dependencies defined in
``environment.yaml``.
